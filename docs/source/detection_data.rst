DetectionData
-------------

.. _detection_data:

``DetectionData`` holds APLOSE-formatted detections in a pandas ``DataFrame``
together with the :class:`~disclose.dataclass.detection_config.DetectionConfig` it was loaded with.
The plotting methods live in :doc:`data.plot <plot_accessor>`.
