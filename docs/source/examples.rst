🐳 Examples
===========

.. _examples:

This section gathers **disclOSE** Jupyter notebooks that demonstrate common workflows, from inspecting a result file to plotting detections and combining acoustic data with glider navigation.

The examples use a small set of result files stored in ``docs/source/_static``. The notebook download links let you run each example locally after adjusting its data paths if needed.

===========

.. topic:: :doc:`Inspect a result file<example_overview>`

    Load one APLOSE result file and review its recording period, annotators, labels, and annotation counts.

===========

.. topic:: :doc:`High-frequency detections<example_HF>`

    Explore detection counts, hourly activity with a polar plot, detection performance, and inter-annotator agreement.

===========

.. topic:: :doc:`Compare several result files<example_LF>`

    Load multiple result files separately and compare them with time-series, heatmap, and scatter plots.

===========

.. topic:: :doc:`Glider data<example_glider>`

    Combine acoustic detections with glider navigation data to plot detections against depth and calculate acoustic diversity.
