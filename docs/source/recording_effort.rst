RecordingEffort
---------------

.. _recording_effort:

``RecordingEffort`` counts, for each time bin, how many ``timebin_origin`` steps were actually recorded.
It is built from the ``recording_file`` of a :class:`~disclose.dataclass.detection_config.DetectionConfig`.
